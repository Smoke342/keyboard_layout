1. Установить AutoHotkey
	Поставить запуск от имени администратора файлов AutoHotkeyU64 и AutoHotkeyU64_UIA по пути C:\Program Files\AutoHotkey\v1.1.37.02 для AHK v.1

2. Установить RU раскладку из папки "russian_fix_altgr"
	Перезагрузить ПК
	Изменить настройки клавиатуры в Windows:
		Параметры → Время и язык → Язык и регион → Русский → Языковые параметры → Клавиатуры - удалить стандартную раскладку, оставить только "Русская без AltGr"
	Назначить в настройках Windows смену языка на горячие клавиши Alt+Shift+8 = EN; Alt+Shift+9 = RU
	
3. Скинуть папку Colemak-DH одной из версии в "C:\Program Files\AutoHotkey"

4. В планировщике задач нужно настроить запуск скрипта:
	Win + R → taskschd.msc
		Создать задачу
			Общие
				Имя: AutoHotKey_Colemak_DH
				✓ Выполнить с наивысшими правами
				✓ Скрытая задача
				Настроить для: Windows 10
			Триггеры → Создать
				Начать задачу: При входе в систему
			Действия → Создать
				Действие: Запуск программы
				Программа или сценарий: wscript.exe
				Добавить аргументы: "C:\Program Files\AutoHotkey\Colemak-DH\start_hidden_bat.vbs"
			Условия
				Убрать чекбоксы "Запускать только при питании от электросети" и "Останавливать при переходе на питание от батарей"
			Настройки
				✓ При сбое выполнения перезапускать через 1 мин.
				Убрать чекбокс "Останавливать задачу, выполняемую дольше:"
			Создать задачу - Ок
		Перезагрузить ПК

5. Посмотреть, не конфликтует ли скрипт с важными горячими клавишами приложений. 
	Назначить горячие клавиши в конфликтующих приложениях:
		Mahou - назначить горячие клавиши: Перевод - Alt+Shift+Ctrl; Транслитерация - Ctrl+Win+Alt
		Ditto - нужно изменить настройки для вставки без форматирования в Word, т.к. ^+v в нем не поддерживается по умолчанию - ЛКМ и Enter поставить на копирование, удалить типы объектов HTML Format и Rich Text Format
		Word - нужно изменить параметр - Файл → Параметры → Дополнительно → Раздел "Вырезание, копирование и вставка" → Снять чекбокс "Показывать кнопки возможностей вставки при вставке содержимого"



Дополнения:
	Горячие клавиши с Ctrl нужно использовать через CapsLock → LCtrl. В редких случаях работает только LCtrl, например Ctrl+Alt+Delete

	Через RAlt не работают стандартные горячие клавиши из-за слоя NumPad

	В целом все горячие клавиши работают стандартно, в редких случаях что-то может не работать, на это влияют скрипт или сторонние приложения

	В exclusion_program.bat можно добавить программы, при запуске которых ahk отключится (после закрытия программы скрипт снова запустится)
